Автоответы в ISO образе - это файлы, где описаны прописаны ответы на вопросы установщика. Установщик читает их и установка происходит без участия человлека.

Буквально, просто текстовый файл. Если установщик не нйдёт в нём ответа - спросит.

Названия: у Debian и Astra это **preseed**, у RedHat и РЕД ОС — **kickstart**, у Ubuntu Server — **autoinstall**, у Windows — **unattend.xml**. Механика одна, синтаксис разный.

# Механика
Берётся обычный образ вендора - распаковывается. Туда кладётся файл с автоответами, после чего в конфиге загрузчика прописывается путь до файла с автоответами. После - образ упаковывается обратно.

Упаковать всё это в один образ - это способ установки, где все эти файлы лежат в одном, что удобно для передаче на флешки, но не удобно по сети. По сети лучше отдавать как есть, не одним файлом.
