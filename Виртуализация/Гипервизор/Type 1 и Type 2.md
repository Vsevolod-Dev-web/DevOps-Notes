***Гипервизор: Type 1*** (bare metal) - этот тип [гипервизора](Гипервизор) работает прямо на железо. Для создания [виртуализации](Виртуализация) на машине этому типу гипервизора не требуется хостовая ОС.

Фактически - это программный слой на железе. Примеры: KVM - этот гипервизор встроен в Linux-ядро. VMware ESXi, Hyper-V, Xen. Это то, что используется в продакшене и на серверах — минимальные накладные расходы, прямой доступ к ресурсам.

Гипервизор: Type 2 (hosted) - это программное обеспечение работающее поверх операционной системы (как и любой другой софт). Примеры: VirtualBox, VMware Workstation, Parallels.

Второй тип "тяжелее" для железа, по сравнению с первым. В последнем - железо напрямую работает со слоем виртуализации, во втором типе - работа производиться через OS.
