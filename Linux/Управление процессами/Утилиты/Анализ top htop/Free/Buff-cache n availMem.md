Ядро выделяет из свободной оперативной памяти кэш (buff/cache). В этот кеш (часть оперативки) записываются данные от процессов которые обычно записываются на хард. Это необходимо для быстрого обращения к файлам со стороны процесса.

## Buffer cache
Buffer cache - это часть оперативки, которую ядро использует для кэширования данных с диска.

Когда процесс читает данные с диска (hdd/ssd), ***ядро копирует эти данные в оперативку***, то есть кэширует. При повторном обращении процесса к этим данным, обращение происходит в оперативку, что очень сильно ускоряет обращение.

При этом, когда эта часть памяти потребуется, ядро моментально их освободит.

Но, ***не всегда***. Есть исключения, при которых ядро просто так не освободит buffer cache:
1. [Dirty Pages](Dirty%20pages)
2. Locked / Mlocked процесс может явно запретить выбрасывать кэш.
3. Shmem и tmpfs
4. Slab (SUnreclaim)

## Available
Available - это значение отображает сколько у нас "реально" доступно памяти. Значение считается по следующему принципу:
```
available ≈ free + buffers + cache - "невыгружаемые" части
```

То есть, available (доступная) - это то, сколько у нас памяти реально свободной и той которую прямо сейчас можно получить, если ядро освободит buffer cache
