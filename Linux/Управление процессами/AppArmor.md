AppArmor - это модуль ядра linux. Она работает как надстройка над правами в Linux и определяет что можно делать конкретной [программе ](Процесс)в Linux.

Это называется мандатный контроль доступа (MAC).

При этом, стоит понимать, что базовые [права](Права%20доступа) привязаны строго к пользователю. Для понимания: [нулевой пользователь](Пользователи) (root) может делать что угодно с любой программой - то есть права доступа к этой программе описаны у пользователя (и не конкретно к программе а в общем).

AppArmor же, в свою очередь, определяет права доступа для определенной программы. Привязывает права к программе.

	Профиль - это набор разрешений для конкретных сервисов.

Профили определяются в `/etc/apparmor.d/`. При этом, по одному на сервис.
Программа определяется по пути к [бинарнику](Бинарный%20файл).

Пример профиля:
```shell
/usr/sbin/nginx {
	/etc/nginx/** r,
	/var/www/** r,
	/var/log/nginx/* w,
	network inet tcp,
}
```
