***rsync*** - это команда для передачи файлов по сети. При этом она работает в обе стороны. Можно как забирать с устройства, так отправлять на него.

При этом, для работы rsync - должен стоять на обеих машинах участвующих в передаче.

Структура утилиты:
```shell
   отправить: rsync -avh /локальный/путь user@ip:/удалённый/путь/
   забрать:   rsync -avh user@ip:/удалённый/путь /локальный/путь/
```

При этом стоит помнить как утилита читает пути:
```shell
ОТКУДА = dir → копируется сам каталог: КУДА/dir/...
ОТКУДА = dir/ → копируется содержимое: КУДА/...
```

Опции: 
`-a (archive)` сохраняет **[права](Права%20доступа)** и время изменения файла. При этом, если на принимающей rsync - работает от root, то и владелец и группа останутся. Иначе - владение будет того кто принял.
Так же, эта опция включает рекурсию для **rsync** - аналогично **-r**

`-v (verbose)` при работе выводит в консоль список передаваемых файлов.

`-h (human readable)` показывает измерения в человеко-читаемом формате

`-n (dry-run)` с этой опцией утилита отрабатывает пробный прогон без передачи.
