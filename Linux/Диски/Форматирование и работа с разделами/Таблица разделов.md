**Таблица разделов** - это, как правило, набор первых секторов диска который **логически** описывает дробление диска на разделы. Грубо говоря - это список.

В таблице описано с какого сектора и каким **[раздел](Раздел%20диска) заканчивается**.

Таблица раздела находиться **ниже** уровня **файловой системы**.

Вот тут можно увидеть таблицу разделов. Для каждого раздела - своя строка.
```bash
$ sudo fdisk -l /dev/sda
Disk /dev/sda: 931.51 GiB, 1000204886016 bytes, 1953525168 sectors
Disklabel type: gpt

Device       Start        End    Sectors  Size Type
/dev/sda1     2048    1050623    1048576  512M EFI System
/dev/sda2  1050624 1953523711 1952473088  931G Linux filesystem
```
Изменение раздела - это прямое изменение этой таблице.

Существует два ***формата*** таблицы разделов:
- MBR таблица целиком помещается в первый [сектор](Файловая%20система) диска. 512 байт. При этом, эта таблица имеет ограничения: максимум 4 раздела, максимум 2 ТБ на раздел. Формат устаревший.
- GPT благодаря тому, что этот формат занимает больше чем один сектор - ограничения снимаются.

К слову. У GPT есть запасная копия таблицы разделов в конце диска. Утилита `gdisk` может восстановить таблицу из запаса GPT.
В MBR можно использовать `testdisk` - утилита просматривает диск и по суперблокам обозначает границы разделов.
