***RAID*** (Redundant Array of Independent Disks) - это объединение нескольких дисков в один массив. У RAID реализует две главные функции: отказоустойчивость и\или скорость.

RAID реализуется тремя базовыми механизмами:
- **Страйпинг**, поверхностно - это объединение нескольких дисков в один. Принцип: диски делятся на блоки (страйпы), из блоков собирается целый "диск". При этом, каждый диск отдельно перестаёт "работать".
  
- **Зеркалирование** - "бинарная механика". Просто, всё что пишется на один диск, точь-в-точь пишется на второй. Буквально - "отзеркаливает". При этом, логично - память обоих дисков уменьшается в двое.
  
  При этом, чтение при зеркалировании быстрее обычного диска, т.к. читать можно сразу с двух одинаковых дисков
  Запись по скорости - не измена при зеркалировании.
  
  При этом стоит понимать, что такой RAID не равно BACKUP. Удаление данных с одного диска, так же вызывает удаление на другом. Зеркалирование может спасти только от физической смерти диска
  
- **Чётность** (parity) - впизду кароче. Какой-то там ебаной магией XOR он вычисляет по контрольным суммам каждого диска, которые занимают 1\3 каждого диска, можно вычислить и восстановить диск.
