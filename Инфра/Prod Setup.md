Для поднятия Prod окружения - самое главное, это безопасность ноды, на которой оно поднимается. Prod - очень чувствителен. В этом окружении крутятся реальные данные, реальных пользователей, падение этого окружения - инцидент.

#### Алгоритм пазовой инициализации Прода
1. Необходимо выбрать железо, определиться сколько необходимо ресурсов для всего, что будет работать на проде.
2. Выбрать и накатить ОС. Чаще всего - Linux дистрибутив
3. Необходимо произвести базовую [инициализацию](initial%20users%20roles%20server%20setup) системы.
4. Настроить firewall, базовую сетевую безопасность.
5. Установить все необходимые [пакеты](base%20packages%20setup) и зависимости.
6. Загрузить исходники службы на сервер. (с GitHub например).
