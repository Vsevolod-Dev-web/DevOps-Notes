В recovery mode на линухе можно поменять пароль для юзера.

1. Запустить образ линухи с внешнего носителя. Запустить рекавери мод.
2. Перемонтировать корень на чтение (В режиме восстановления корень примонтирован только на чтение) `mount remount,rw /`
3. Командой поменять пароль на юзера `passwd administrator`
4. `exit > exit > exit`
