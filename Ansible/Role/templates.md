В этой папке лежат файлы кофнигов на языке шаблонов Jinja2 с подстановками. Отлично подходит для тюнинга конфигов на таргете. 

Файлы в этой директории лежат в формате языка `.j2`. 

Подстановки в файле указываются следующим образом: `{{ variable }}`
Пример шаблона:
`templates/nginx.conf.j2`
```python
user www-data;
worker_processes {{ nginx_worker_processes }};
```

Шаблон применяется через [модуль](Модуль) `ansible.builtin.template`. Как и с любым модулем, Ansible берёт модуль, подставляет указанные значения в указанные места и результат отправляет на таргет подменяя там конфиг.

```yaml
- name: Тюнинг nginx конфига
  ansible.builtin.template:
    src: nginx.conf.j2          # откуда взять шаблон
    dest: /etc/nginx/nginx.conf # куд класть на таргете
    # далее указываются параметры файла на таргете
    owner: root
    group: root
    mode: '0644'
  notify: restart nginx
```

Когда модуль собирается на control-ноде, он видит все переменные: [роли](Role) ([default](default), [vars](vars)), [в инвентори](Inventory), [facts](facts) и т.д 
Далее он парсит шаблон и подставляет все значения. И в завершение - отправляет и подменяет файл на таргете.
