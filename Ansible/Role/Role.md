***Role*** - в [Ansible](Ansible), это *переиспользуемый* набор задач (tasks), переменных (vars), файлов и шаблонов (templates) организованных по строгому **соглашению** о каталогах Ansible.

Ansible знает об этом соглашении. Он знает соглашение, и в каких папках что искать, роли нужно писать под него.

***Структура Role***
```
roles/postgresql/
├── tasks/main.yml        # ГЛАВНОЕ: список задач (то, что раньше было в плейбуке)
├── handlers/main.yml     # задачи-реакции (про них позже)
├── defaults/main.yml     # переменные по умолчанию — низший приоритет
├── vars/main.yml         # переменные роли — высокий приоритет
├── templates/            # шаблоны Jinja2 (конфиги с подстановками)
├── files/                # статичные файлы для копирования как есть
├── meta/main.yml         # зависимости от других ролей, метаданные
└── README.md
```
