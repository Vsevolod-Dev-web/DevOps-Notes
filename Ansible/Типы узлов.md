В автоматизированной настройке участвуют следующие узлы:
- Control Node (Узел Управления)
- Managed Node (Таргет, Управляемый Узел).

### Control Node
Как правило, control node ставиться на UNIX системах. Но у некоторых других так же есть нативная поддержка, кроме Windows. 

Самое главное требование для Control Node - на ОС должен присутствовать python.

---
### Managed Node
MN, фактически, может быть любой. Но стоит учитывать, что есть различие в настройки Win и UNIX системах. 

---

***Главное различие*** - на UNIX таргетах запускаются [модули](Модуль) на python.

На Win - модули на PowerShell. Это связано с тем, что на Win нет нативной поддержки python. 

Так же, на Win нету нативной поддержки SSH и для подключения используется [WinRM](WinRM).
