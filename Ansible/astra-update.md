Официальная дока Astra Linux предупреждает: использовать `apt update` и `apt upgrade` крайне **не рекомендуется**. 

В связи с защитой целостности системы мандатного контроля - при попытках пакета apt изменить систему (изменить бит пакета), мандатный контроль это запретит и система может сломаться.

Для безопасного обновления Astra Linux рекомендуется использовать **официальный пакет** `ansible-module-astra-update` (да, это именно пакет на Таргете). Этот пакет необходим для использования Ansible-модуля astra_update и должен стоят на таргете перед использовании модуля на нем.

Суть пакета - он отключает систему защиты целостного контроля, обновляет пакеты, включает защиту обратно.

**При этом важно** - если установить пакеты из неофициальных репо астры - это может:
- Нарушению мандатных меток безопасности файлов.
- Потере сертификации системы.
- Нестабильной работе и сбоям.

По этому, Астра рекомендует использовать этот пакет для накопленных обновлений
