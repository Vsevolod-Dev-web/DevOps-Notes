Jinja2 шаблонизатор имеет структуру цикла. Работают так же, как и [loop ansible](loop). 

Пример, шаблон `pg_hba.conf`:
```jinja2
# Added with Ansible push
{% for rule in pg_hba_rules %}
{{ rule.hba_type }} {{ rule.hba_database }} {{ rule.hba_user }} {{ rule.hba_address }} {{ rule.hba_method }}
{% endfor %}
```

Переменные передаются в шаблон ***[inline-словарями](YAML)***: 
```yaml
pg_hba_rules:
- { type: host, database: all, user: all, address: 192.168.1.0/24, method: scram-sha-256 }
```
