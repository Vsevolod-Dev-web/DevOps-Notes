***Windows Remote Management*** - это встроенный в Windows протокол удаленного управления. Технически это веб-сервис (http/https), который слушает входящие команды и выполняет их в системе. 

На linux таргетах для этого используется *ssh.*

Control Node подключается к системе как обычный пользователь. Поэтому, в системе на таргете необходима "точка входа" для control node - отдельный пользователь с которого будет происходить настройка системы.

По стандарту, для подключения control node через WinRM используется порт ***5986 (HTTPS)***.
