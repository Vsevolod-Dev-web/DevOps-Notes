***Модуль*** - это скрипт, что-то выполняющий на таргете. Основа декларативного кода. Фактически, ты говоришь модулю как должно быть, после чего он приводит систему таргета к этому состоянию.

**Пример:**
- модуль `win_service`. На N-target должна быть запущенна A-служба. Модуль смотрит, если она не запущена - запускает. Если запущена - ничего не трогает.

К слову, ansible является ***идемпотентным***. Если модуль видит, что что-то уже есть, он это трогать не будет и вернёт `changed:false`. Фактически модуль не делает действия каждый раз заново - он проверяет состояние, если всё как декларировано - не трогает.

***НО*** есть исключение, модули `win_shell / win_command` - они жестко запускают действия. К ним стоит прибегать только если не нашлось специализированного модуля.

Модули на Linux и Win таргетах разные.
- На linux модули написаны на python скриптах
- На win на powershell, т.к. нативно на win python нету.

Модули пишут разрабы ansible, вендоры (например microsoft, cisco пишут модули под свой софт), комунити. 
Скорее всего тебе не придётся писать свои модули.
Необходимо только подключить коллекцию модулей. Например для Win: `ansible-galaxy collection install ansible.windows`
