# linux-server-base

	Сей документ описывает логику linux-server-base роли в Ansible. 
	Главная суть роли - вне зависимости от семейства дистрибутива, настроить сервер-таргет для минимальной работы

Данная роль автоматизирует базовую настройку linux-машин.

Главная фишка роли - multi-distro роль. Динамическое подключение тасок и варсов для той дистры что указана после сбора gather facts.

Быстро по таскам в порядке их отработки:

Создание админских юзеров. Юзеры берутся из списка с 2 элементами: имя и хеш пароля. Рекурсивно создаются админы из списка списков. 
Добавляются необходимые группы - перечислены в переменной groups.

Устанавливается pdpl если система астра на каждого юзера - берётся варса что и в первой таске, но только item.name

 Дла астра линукс: скидывается конфиг /etc/apt/sources.list с актуальнымм ссылками на репозитории

Делается апт абдейт, устанавливаются пакеты из списка перечисленного в варсах
