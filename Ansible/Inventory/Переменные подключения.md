Задавая ***[переменные](vars) подключения*** можно настраивать как и к кому будет подключатся [control node](Типы%20узлов). Эти переменные задаются в [inventory-файлах](Inventory). Переменные можно присваивать сразу к группе [таргетов](Типы%20узлов).

Учитывая, что в один таргет может быть в нескольких группах сразу, стоит понимать как работает назначение переменных к таргету. Тут вступает в силу правило ***precedence***
(*приоритет*) переменных. Звучит оно так:

```
Чем "спецефичнее" источник - тем выше приоритет. Если приоритет важный - побеждает тот, что стоит выше по алфавиту.
```

|Приоритет|Источник|Смысл|
|---|---|---|
|Низший|`[all:vars]`|для всех хостов|
|↓|`group_vars/` обычной группы|для группы|
|↓|`group_vars/` дочерней группы|child бьёт parent|
|↓|host vars (рядом с хостом или в `host_vars/`)|для одной машины|
|↓|`vars:` внутри плейбука|для конкретного play|
|Высший|`-e "var=value"` в командной строке|для этого запуска, бьёт всё|

## Пример
Пример:

```ini
[windows]
winTarget1 ansible_host=192.168.1.50

[windows:vars]
ansible_user=ansible
ansible_password=Ansible123!
ansible_connection=winrm
ansible_port=5986
ansible_winrm_scheme=https
ansible_winrm_transport=basic
ansible_winrm_server_cert_validation=ignore
```

| Переменная                                    | Что делает                                           | Linux-аналог       |
| --------------------------------------------- | ---------------------------------------------------- | ------------------ |
| `ansible_user=ansible`                        | Под каким юзером входить                             | `ssh ansible@host` |
| `ansible_password=Ansible123!`                | Пароль этого юзера                                   | пароль/ключ SSH    |
| `ansible_connection=winrm`                    | **Ключевое.** «Это Windows, используй WinRM, не SSH» | по умолчанию `ssh` |
| `ansible_port=5986`                           | Порт WinRM (HTTPS)                                   | порт 22 у SSH      |
| `ansible_winrm_scheme=https`                  | Шифрованный канал                                    | —                  |
| `ansible_winrm_transport=basic`               | Метод аутентификации (для теста простой)             | —                  |
| `ansible_winrm_server_cert_validation=ignore` | Не проверять самоподписанный сертификат VM           | —                  |
