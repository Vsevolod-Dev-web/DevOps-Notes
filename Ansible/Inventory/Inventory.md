***Inventory*** - это список [таргетов](Типы%20узлов). Control node должна знать, кем управлять.

Формат у inventory-файлов простой: `ini`

Фактически - это просто конфиг файлов с перечислением адресов managed nodes. При этом, таргеты в файле ***сгруппированы***.

Базовый inventory:
```ini
[windows]
winTarget1 ansible_host=192.168.1.50
```

- [windows] - это группа хостов. Имя может быть любое. Группировка необходима, чтобы одним разом запушить настройку на множество таргетов, просто указав группу.
- `winTarget1` - это просто название таргета. Псевдоним. Это не фактическое название узла.
- `ansible_host=192.168.1.50` - это реальный IP-адрес таргета.
