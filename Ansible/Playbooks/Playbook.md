***Плейбуки*** пишутся на языке автоматизации **[YAML](YAML.md)**. 

***Плейбук*** - это файл в котором декларативность описано состояние [таргета](Типы%20узлов). [Ansible](Aansible) читает этот файл и при приводит систему к необходимому состоянию с помощью [модулей](Модуль)

Иерархия плейбука, чтобы не путать Playbook, плея и [tasks](tasks.md):
```
Плейбук (playbook)         ← файл .yml целиком
  └─ Плей (play)           ← блок "что делаем и с кем"
       └─ Таск (task)      ← одно конкретное действие
            └─ Модуль      ← инструмент, которым действие выполняется
```

У каждого элемента списка () есть свои ***ключи*** (свойства). К примеру, `hosts:` - это свойства плея, в которое передаются адреса таргетов.
