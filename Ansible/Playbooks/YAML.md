YAML - это просто файл где структурированно записаны данные, так что человек может это читать. 

Две основные вещи которые читает yaml и работает с ними:

***Список*** (list) - перечисление элементов. Маркируется дефисом `-`:
```yaml
- element
- elementPussy
- elementGrock
```

***Словарь*** (dictionary / map) - пары <ключ:значение>. Маркируется через двоеточие:
```yaml
name: Bob
city: Donbass
role: Miner
```

	Дефис ставится перед элементом списка. Если перед строчкой нет дефиса — она ключ словаря, а не элемент списка.

*Плейбук - это комбинация двух этих структур. Списки словарей, словари с списками и т.д.*

# Синтаксис
Для понимания того, как YAML видит написанный декларативный код, необходимо знать 3 главных правила:

***Правило 1. Отступы - исключительно пробелы***
В YAML, как и в python вложенность определяется отступами. При этом, YAML не воспринимает табуляцию, и одна вставленная табуляция может сломать весь плейбук.

В YAML для отступов строго используются пробелы. Один уровень вложенности - это ***2 пробела.***
```yaml
parant:
  child1: alex
  child2: gorge
  child3: gay
    grandChild: died
```

***Правило 2. После двоеточия - пробел***
Это может быть не интуитивно для Linux-пользователей. Но, в YAML, в синтаксисе ***словарей***, после двоеточия обязательно ставится пробел:

```yaml
name: IIS        # правильно — пробел после :
name:IIS         # СЛОМАНО — нет пробела
```

***Правило 3. Уровень по отступам - одна принадлежность***
Отступы - главное мерило принадлежности. Если элемент сдвинуть на 2 пробела - он станет вложенным. Справедливо и обратное (станет вложенным на уровень ниже).

Ну тут все интуитивно.

`- { name: vsevolod, password: 123 }` - такой синтаксис называется ***flow-sytle***, inline-словари.
Это воспринемается так же, что и:  
```yaml
- name: vsevolod
  password: 123
```

То же с списками. Block:
```yaml
- яблоко
- груша
- слива
```
Flow:
```yaml
[яблоко, груша, слива]
```
