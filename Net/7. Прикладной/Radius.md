Radius (Remote Authentication Dial-In User Serviece) - это сетевой протокол централизированной аутентификации пользователей в сети.

Основные функции (AAA):
- Authentication (Аутентификация) - проверка личности пользователя (логин и пароль)
- Authorization (Авторизация) - определение прав доступа получаемых к сетевому ресурсу
- Accounting (Учёт) - фиксация времени начала и окончания сессии, объёма переданных данных. Журналирование.

**Radius** по стандарту использует два порта: 1812 (UDP, этот порт используется для первой функции AAA - аутентификации) и 1813 (используется для функции accounting)
