***Nginx*** (Читается как "ЭНДЖИН ИКС") - это служба которая выполняет несколько функций. Обычно Nginx упоминается как веб-сервер. Функции которые Nginx может выполнять:
- ***Раздача статики.*** Это самое простое что он может делать. Брать html\css\js статику с диска и отправлять по запросу.
- ***Балансировщик нагрузки.***
- ***TLS-расшифровщик.*** Может разобрать HTTPS и гонять HTTP.
- ***Revers Proxy.*** Может взять пришедший запрос и перенаправить его на другую службу (Например на API).

Nginx, сидит демоном в системе и слушает порты 80 и 433 (HTTP и HTTPS).

### Раздача статики
Если Nginx работает как ***раздатчик статики***, то когда на слушаемый им порт приходит http запрос на страничку, то он, грубо говоря, превращает URL в путь к файлу на диске и отдаёт статическую HTML страничку.

То есть, на запрос по порту Nginx ***читает файл с диска***.

Nginx не самый умный. Раздача статики крутиться на понятии **document root**. То есть корневая директория документа.

Этот document root указывается, и тогда Nginx действует так:
1. Знает что document root например: `/var/www/coinview`
2. Получает запрос `GET /page/app.js`
3. "Склеивает" document root и запрашиваемый адрес: `/var/www/coinview + /page/app.js`
4. Переходит в полученную запросом директорию, если файл есть - отдаёт его. Если нет - 404.

Если у Nginx после запроса получилась директория, то он ищет в этой директории файл `index.html`
