***Firewall*** - это система ограничений трафика в сети. Firewall позволяет писать правила ограничивающие входящий\выходящий трафик. 

Firewall применят правило **сверху вниз**. *То есть широкое в сомом верху полностью нивелирует любое специфичное ниже.* От этого исходит, что порядок правил абсолютно важен. 

**Input** - обрабатывается входящие пакеты на устройстве. С любого адреса на адрес текущего узла. Используется для защиты конкретного узла. 

**Forward** - обрабатывает транзитные пакеты. Из одной подсети в другую(ие). Настраивается на маршрутизаторах.

**Output** - обрабатывает пакеты генерируемые на самой машине. Запрос к ntp-серверу например.

При этом, у каждой цепочки есть подцепочка. Для примера:

INPUT
  ├─ 1. ufw-before-input   ← системное: loopback, conntrack, ICMP
  ├─ 2. ufw-user-input     ← ТВОИ правила (allow 22, allow 5432...)
  ├─ 3. ufw-after-input    ← добивка: тихо отбросить широковещание
  └─ 4. политика deny      ← если ничего не совпало

Если в цепочке input, forward, output фервол решает какая из низ по ip назначения, то подцепочки отрабатывают по порядку.

1. Обрабатывает события до действий юзер.
2. Действия юзера
3. После действий юзера
4.
