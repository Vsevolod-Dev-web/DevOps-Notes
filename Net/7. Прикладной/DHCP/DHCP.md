DHCP - это протокол автоматизирующий раздачу [ip-адрессов](ip-адрес) в сети.

При подключении в сеть, каждая сетевая карта опрашивает сеть дать её IP-адресс.

DHCP сылыт этот запрос - удовлетворяет его и при этом устанавливает параметры на время пользования (аренду).

При этом, на старте, когда устройство только подключили к сету - у него нету IP-адреса. От чего, dhcp посылает [broadcast](ARP)-запрос и единственный идентификатор в сету у устройства - [MAC](MAC)

Говорить, что DHCP раздаёт ip - это грубо. В действительности, DHCP раздёт конфигурацию. IP-адрес, шлюз, DNS.

Всё это, помимо IP передаётся **опциями**.

***Опции*** - это дополнение дополнительные значения к конфигу. Опция, ключ - это числовое значение. А само значение - это строка, IP или число.

*Для примера:*
Клиент спрашивает: дай мне 1, 3, 6, 66.
Сервер отвечает: вот они
```
1  → маска
3  → шлюз
6  → DNS
```


| Опция   | Зачем тебе                                                                                                                                 |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 6, 15   | DNS-серверы и search domain — почему в поде резолвится короткое имя                                                                        |
| 42      | NTP — разъезд времени ломает TLS, Kerberos, логи, распределённые БД                                                                        |
| 26      | MTU — вот это больно. Overlay-сети (VXLAN, WireGuard) режут MTU, и если DHCP раздаёт 1500, ты получаешь «ssh работает, а git clone виснет» |
| 121     | Дополнительные маршруты без ручной прописи                                                                                                 |
| 66, 67  | Куда идти за загрузчиком — база PXE                                                                                                        |
| 224–254 | Свободный диапазон под своё: адрес конфиг-сервера, окружение, что угодно для ZTP/автопровижининга                                          |
