На сетевых железках в один момент находятся 2 файла конфигурации:

# running-config
Это текущая "боевая" конфигурация. Изменение конфигурации в CLI, записывает их именно в этот файл.

```cli *Privilaged EXEC
Router# show running-configuration
```

# startup-config
Это файл конфигурации, который применяется на устройство при его запуске.

```cli
Router# show startup-configuration
```

Стоит понимать, что startup-config нужно "применять" - записывать running-config в startup-config, иначе при запуске будет применятся default-config.
Чтобы сохранить running-config в startup* можно использовать один из способов:
```cli
Router# write
Building configuration...
[OK]

Router# write memory
Building configuration...
[OK]

Router# copy running-config startup-config
Destination filename [startup-config]?
Building configuration...
[OK]
```
