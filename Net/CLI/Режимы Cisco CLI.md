CLI (Command Line Interface) - интерфейс командной строки. Используется для взаимодействия с сетевыйм устройством.

Касаясь оборудование CISCO, в CLI есть "режимы":
***user EXEC***: (Определяется символом `>` после названия устройства)
```cli
Router>
```
Ограниченный режим, в нём можно только смотреть, и то не всё: `PING`, `TRACEROUTE`, часть `show`

***Privileged EXEC:*** (определяется символом `#` после названия устройства)
```cli
Router#
```
Нельзя глобально ничего менять, но управлять железкой уже можно. Ребутнуть, поменять время или посмотреть полный show.

***configure mode:*** (определяется надписью `(config)#` после названия устройства)
```cli
Router(config)#
```
Режим глобальной конфигурации. Тут уже можно делать всё - полностью настроить устройство. Каждое действие применяется сразу. (На Eltex-ах изменения приминяются только после `confirm`)
