Это стандартизованные диапазоны IPv4 (RFC 6890 — сводный документ, объединяющий RFC 1918, 5735 и другие).

| Диапазон             | CIDR | Назначение                                                                                                                       | RFC      |
| -------------------- | ---- | -------------------------------------------------------------------------------------------------------------------------------- | -------- |
| `0.0.0.0/8`          | /8   | «This network» — используется только как source-адрес при загрузке (когда устройство ещё не знает свой IP)                       | RFC 1122 |
| `10.0.0.0/8`         | /8   | **Private** — внутренние сети                                                                                                    | RFC 1918 |
| `100.64.0.0/10`      | /10  | **Carrier-Grade NAT** — провайдеры используют, когда у них кончились публичные IP. Видишь у себя на роутере — значит ты за CGNAT | RFC 6598 |
| `127.0.0.0/8`        | /8   | **Loopback** — `127.0.0.1` это localhost. Весь /8 принадлежит loopback'у                                                         | RFC 1122 |
| `169.254.0.0/16`     | /16  | **Link-local** — автоматический адрес, когда DHCP не ответил. Видишь у себя — DHCP мёртв                                         | RFC 3927 |
| `172.16.0.0/12`      | /12  | **Private** — внутренние сети (`172.16.0.0` — `172.31.255.255`)                                                                  | RFC 1918 |
| `192.0.0.0/24`       | /24  | IETF protocol assignments                                                                                                        | RFC 6890 |
| `192.0.2.0/24`       | /24  | **TEST-NET-1** — для документации и примеров, в проде запрещено                                                                  | RFC 5737 |
| `192.88.99.0/24`     | /24  | 6to4 anycast (устаревшее)                                                                                                        | RFC 7526 |
| `192.168.0.0/16`     | /16  | **Private** — домашние сети                                                                                                      | RFC 1918 |
| `198.18.0.0/15`      | /15  | Benchmarking — для тестов сетевого оборудования                                                                                  | RFC 2544 |
| `198.51.100.0/24`    | /24  | **TEST-NET-2** — документация                                                                                                    | RFC 5737 |
| `203.0.113.0/24`     | /24  | **TEST-NET-3** — документация                                                                                                    | RFC 5737 |
| `224.0.0.0/4`        | /4   | **Multicast** — вещание группе устройств. `224.0.0.0` — `239.255.255.255`                                                        | RFC 5771 |
| `240.0.0.0/4`        | /4   | **Reserved** — бывший «Class E», зарезервирован для будущего использования. `240.0.0.0` — `255.255.255.254`                      | RFC 1112 |
| `255.255.255.255/32` | /32  | **Limited broadcast** — «всем в моей сети сразу»                                                                                 | RFC 8190 |

Всё остальное (примерно `1.0.0.0` — `223.255.255.255` за вычетом перечисленного выше) — **публичный IPv4**, который раздаёт IANA провайдерам и крупным организациям.
