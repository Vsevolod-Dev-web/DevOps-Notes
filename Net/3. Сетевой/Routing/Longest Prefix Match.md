**Longest Prefix Match** - это правило, которое ядро применяет для определения куда отправить пакет, смотря в таблицу маршрутизации.

Два главных критерия для выбора:
1. Совпадение адреса сети.
2. Чья маска больше (Na > Nb), туда и отправлять

Ядро всегда отправляет на маску которая больше, если адрес совпадает, т.к. это более специфичное определение сети. Скажем у нас есть следующие записи:
```
default              via 192.168.5.1
192.168.5.0/24       dev wlp1s0
192.168.5.128/25     via 10.0.0.1
```
Если адрес получателя - 192.168.5.200. Куда он пойдёт? Все три записи подходят под адрес. Ядро смотрит на маски 0 < 24 < 25. Отправляем на 25.

Если бы адрес был 192.168.5.50. Тогда, под 192.168.5.128 он не попал бы. Для лучшего понимания, сравним побитово:
192.168.5.128 (начало с маской 25)
`11000000.10101000.00000101.1 0000000`
192.168.5.50
`11000000.10101000.00000101.0 0110010`
Видим, что адрес сети не совпадает, дальше уже этот вариант не рассматриваем.

Фактически - это сравнение, побитовое. двух адресов:
- Адрес получателя
- Адрес подсети, записанный в таблице маршрутизации.

Сперва, ядро переводит адрес получателя в биты.
```
11000000.10101000.00000101.00000000   ← 192.168.5.0
←─── 24 бита сети ────────→ ←8 бит хостов→
```
смотрит на адрес сети. 

После чего, переводит в биты все адреса записанные в таблице маршрутизации. И начинает сравнивать.

**Пример.** 

У нас есть адрес получателя: 192.168.5.42, в битах:
```
11000000.10101000.00000101.00101010
```

В таблице у нас следующее:
```
default              (0.0.0.0/0)         via 192.168.5.1
192.168.5.0/24       dev wlp1s0
```

Начинает проверку, смотрит сеть 192.168.5.0\24:
```
Получатель:  11000000.10101000.00000101 . 00101010
Сеть:        11000000.10101000.00000101 . 00000000
             ←──── совпадает 24 бита ──→ ← не смотрит →
```
Совпало, запись подходит, **N=24**

Теперь смотрим сеть [default](default%20gateway.md) = 0.0.0.0\0.
- Сравниваем **первые 0 бит**. То есть не сравниваем вообще ничего.
- Формально подходит → **N=0.**

В обеих записях - совпадение по адресу сети. Далее, ядро смотрит на маску, чья больше - туда и отправляет.
