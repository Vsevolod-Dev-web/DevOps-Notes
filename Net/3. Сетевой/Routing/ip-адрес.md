**IP-адресс** - это главное, обязательное условие для передачи данных по сети. Если смотреть глобально (на 3 уровне и выше). Если при отправки нету MAC-адреса назначения, передача состоится благодаря [ARP](ARP.md). 

Если нету IP-адреса назначения, передаче не может состояться, т.к. пакет при отправке просто не соберётся - выделенные 32 бита заголовка под destination ip будут пустые - получится ошибка host unreachable.

ip-адрес - это 32 битное число, указывающее на адрес устройства в сети. По модели OSI - это 3 уровень (сетевой).

ip-адрес - это 4, 8 битных числа, разделённые точкой (октет). Вид:

```
192       .168       .5         .0
11000000  .10101000  .00000101  .00000000
```
