Минимальная часть данных передаваемых по сети - это ***пакет***.

Предположим, что по сети передаётся файл 100 MiB. Этот файл не будет передаваться одним куском. Он разбивается на мелкие части, и вот одна эта мелкая часть - это и есть ***пакет***.

У пакета есть структура, грубо так:
```
[ заголовок | данные ]
```

Когда пакет идёт по модели OSI к нему добавляются заголовки каждого уровня:
```
[ HTTP данные ]
[ TCP заголовок | HTTP данные ]
[ IP заголовок  | TCP заголовок | HTTP данные ]
[ MAC заголовок | IP заголовок  | TCP заголовок | HTTP данные ]
```
