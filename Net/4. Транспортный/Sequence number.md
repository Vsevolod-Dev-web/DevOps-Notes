В [TCP](TCP) заголовке каждого пакета есть ***Sequence number*** - это нумерация байт данных. Грубо говоря, протокол указывает на байт начала пакета.

Пример: Передаётся файл 3000 байт, фрагментируется на 3 сегмента по 1000 байт. 
- Сегмент 1: seq = 0 (байты 0-999)
- Сегмент 2: seq = 1000 (байты 1000-1999)
- Сегмент 3: seq = 2000 (байты 2000-2999)

Это счётчик.

При этом, стоит понимать, что это значение не глобальное. Его каждая нода определяет [сама для себя...](three-way%20handshake)

Фактически - это просто счётчик, который каждая сторона [TCP](TCP) соединения заводит сама для себя, начиная с произвольного стартового числа (*Initial Sequence Number, ISN*).

**ISN - это случайное число, от которого идёт дальнейший sequence number.** 

В одном TCP соединении два потока = клиент→сервер и сервер→клиент. И чтобы соединение было безопасным используется процесс [рукопожатия](three-way%20handshake)
