***pg_dump*** - бинарник для создания [дампа](DB%20Dump) psql. Утилита создаёт dump конкретной базы данных, можно использовать несколько форматов. 

Так же есть ***pg_dumpall*** - эта утилита создаёт dump всего [DB кластера](pSQL%20on%20Server).

#### Форматы dump'a
У `pg_dump` есть 4 формата, флаг `-F`:
- `pg_dump -Fp` - **plain** (***по умолчанию***). Простой SQL-текстовик, последовательность `SELECT`, `INSERT`, `JOIN` и т.д. 
  Восстанавливается через `psql db_name < dump.sql`.
  Такой формат можно грепать и можно читать, что удобно. Но есть минусы - он большой, не сжат. И при этом, нельзя восстановить часть, т.к. оно происходит последовательно.
- `pg_dump -Fc` - **custom**. Этот формат нельзя прочитать. Он сжат, компактен. Можно восстанавливать через `pg_resotre -t`. **Самый рекомендуемый для бэкапов формат.**
- Есть еще 2 формата. (Гугли `-Fd` и `-Ft`)

#### Инструмент восстановления Dump
Для восстановления формата ***plain*** используется бинарник psql. Для остальных - pg_restore.

Это так, потому что plain-формат - это просто голый sql текст. Любой клиент который умеет читать SQL скрипты сможет его восстановить - просто последовательно запустить команды.
