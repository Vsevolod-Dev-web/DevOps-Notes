На ubuntu 24.04, [latest stable release model](Пакетные%20менеджеры) psql - 16. Чтобы накатить последнюю версию, необходимо в [APT](Пакетные%20менеджеры) подключить официальные репо с билдами - PGDG.

Для установки пакетов с репо, не из официального пула, иногда необходимо устанавливать сертификаты. Для того, чтобы ПК доверял устанавливаемым файлам и зависимостям.

`sudo apt install curl ca-certificates`: Набор корневых сертификатов, чтобы ваша система доверяла HTTPS-соединению с сайтом PostgreSQL.
