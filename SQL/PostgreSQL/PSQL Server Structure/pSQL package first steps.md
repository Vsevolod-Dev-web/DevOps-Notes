После того, как PostgreSQL ставится в систему `sudo apt install postgresql`, обязательно происходит следующее:

1. Подтягиваются пакеты `postgresql-16`, `postgresql-client-16`, `postgresql-common` и зависимости
2. Создаётся системный пользователь `postgres`
3. Инициализируется кластер (initdb) `/var/lib/postgresql/16/main/`. (Создаётся каталог с файлами)
4. Конфиги ложатся в `/etc/postgresql/<version num (16)>/main/`
5. Сервис зарегистрируется в systemd и автоматически запуститься.
6. Откроется порт 5432, но только на localhost по умолчанию.


*initdb - это служба, которая создаёт новый кластер на диске. Не запускает демона, не открывает порты. Просто создаёт директорию.
