- `base/` — собственно файлы баз данных. Внутри подкаталоги с числовыми именами — каждая база PostgreSQL это директория, каждая таблица — файл внутри
- `global/` — общие для всего кластера данные (список ролей, базы данных, табличные пространства)
- `pg_wal/` — **Write-Ahead Log**, журнал транзакций. Каждое изменение сначала пишется сюда, потом в базу. Это даёт ACID-гарантии при сбоях
- `pg_xact/` — статусы транзакций (commit/abort)
- `pg_tblspc/` — табличные пространства
- `PG_VERSION` — текстовый файл с версией кластера (`16`)
- Ещё несколько служебных каталогов

Каждый кластер полностью изолирован от других.
