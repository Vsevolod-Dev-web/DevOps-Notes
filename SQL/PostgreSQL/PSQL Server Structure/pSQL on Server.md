### 0. One-shot
Служба `postgresql.service` - это [one-shot](unit-файл), который запускает сервера, которые поднимают и держат кластеры баз данных. Этот процесс перед завершением форкает процессы, которые держат демона, управляющего кластером.

# 1. Postgresql Daemon
Демон `postgres`, это **сетевой сервер** (как nginx, sshd), который сидит в памяти и слушает стандартный порт 5432 (TCP). Задача этого процесса обрабатывать запросы приходящие на слушаемый ею порт. Под запросом, следует строго понимать именно *сетевые запросы.*

# 2. Кластер баз данных
В терминологии PostgreSQL - кластер это набор баз данных, управляемых одним сетевым сервером (postgre). Грубо говоря, это просто набор файлов баз в директории.

# 3. Системный пользователь
`postgres` - это [системный пользователь](Пользователи), создаётся автоматически при установки. Весь кластер принадлежит ему.

# 4. Внутренний пользователь СУБД
Это отдельная сущность - никак не связанная с юзерами в системе. По умолчанию создаётся суперпользователь СУБД - `postgres`
