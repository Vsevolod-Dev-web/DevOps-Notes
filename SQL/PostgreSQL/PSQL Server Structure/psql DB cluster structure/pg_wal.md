***pg_wal (postgre Write-Ahead Log)*** - грубо говоря, это система архивации. Все изменения в базе сначала записываются сюда и хранятся тут в зависимости от конфигурации кластера. И только потом, без участия пользователя изменения безопасно записываются в базу. 

Если сервер с базой упал, после ребута postgre смотрит сперва сюда, в архив.

***Это и есть Durability в [ACID](ACID)***
